# SOP: Integração Desktop & Connector Companion

## Procedimento
1. Para ligar o computador do utilizador à cloud: aceder a `/connector` e descarregar o instalador do Companion (Tauri v2 / Go).
2. Gerar o código de emparelhamento rápido de 6 dígitos.
3. Selecionar as pastas locais de trabalho para indexação RAG automática (armazenamento híbrido).
4. O agente cloud ganha a capacidade de consultar e pesquisar documentos locais de forma segura.
