# SOP: Agendamento e Redes Sociais (SocialFlow)

## Procedimento
1. Criar ou adaptar texto e hashtags para cada rede (LinkedIn, Instagram, X).
2. Consultar o calendário de publicações para evitar sobreposição de horários.
3. Submeter para agendamento com data/hora definidas através da página `/socialflow`.
4. Publicações em canais oficiais podem requerer aprovação prévia na aba de Aprovações.
